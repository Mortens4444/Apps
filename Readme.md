### Kalmár

**Status:** 🟡 Early Access

*A modular enterprise management system for Hungarian SMEs.*

Integrates partner management and CRM, NAV Online Invoice e-invoicing, payroll and HR administration, accounting, inventory management, and e-commerce into a single system. A shared data model serves mobile and desktop clients as well as the server-side components.

- **Platforms:** Android, Windows

### LiveView Agent

**Status:** 🟡 Early Access

*A live camera streaming agent for remote monitoring.*

A mobile agent for the LiveView system used by the Sziltech IPVS47 video recorder family. Turns a phone's camera into a live video source and streams footage over the network to a monitoring client.

- **Platforms:** Android, Windows

### MindForge.EV3

**Status:** 🟡 Early Access

*Bluetooth control for LEGO Mindstorms EV3 robots.*

Connects to EV3 bricks via Bluetooth, provides direct control of motors and sensors, and helps users program their robots through a single cross-platform client.

- **Platforms:** Android, Windows

### Snake Reloaded

**Status:** 🟡 Early Access

*The classic Snake game with a modern twist.*

A modern, .NET MAUI-based take on the classic Snake game, featuring a Bluetooth Low Energy multiplayer mode that lets two devices compete against each other in a test of reflexes.

- **Platforms:** Android, Windows
